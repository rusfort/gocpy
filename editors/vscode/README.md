# Gocpy для VS Code

Поддержка языка [Gocpy](https://github.com/rusfort/gocpy):

- подсветка синтаксиса `.gocpy` (ключевые слова, f-строки, аннотации `@throws`/`@overload`, директивы `//gocpy:`);
- иконка языка для файлов `.gocpy` в проводнике и на вкладках;
- комментарии, автозакрытие скобок, отступы.

Иконка показывается в стандартной теме значков Seti и в любой теме, где нет своей иконки для Gocpy.
